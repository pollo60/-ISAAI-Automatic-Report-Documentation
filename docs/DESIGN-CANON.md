# ISAAI design canon (neutral corporate)

Apply to `Project Charter.html`, `Project Plan.html`, presentations, and new markdown/HTML artifacts. **No employer branding or identifiable internal program names.**

## Color

| Token | Hex | Use |
|-------|-----|-----|
| `--brand-primary` | `#00335b` | Headers, table heads, key labels |
| `--brand-secondary` | `#00508f` | Links, accents |
| `--text-main` | `#333333` | Body |
| `--text-muted` | `#666666` | Secondary text |
| `--bg-slide` | `#ffffff` | Slide/document background |
| `--bg-canvas` | `#eef2f5` | Page canvas |
| `--status-positive` | `#007a33` | In-scope, success |
| `--status-negative` | `#d11241` | Out-of-scope, risk |
| `--status-warning` | `#e37222` | Caution |
| `--border-color` | `#d1d5db` | Borders |

## Typography

- **Font stack:** Arial, Helvetica Neue, Helvetica, sans-serif
- **Section titles:** Uppercase, letter-spacing 0.1–0.12em, weight 700, primary color
- **Body:** 0.85–1rem, line height comfortable for print

## Shape and layout

- **Border radius:** 2px (tags/pills may use full radius)
- **Max document width:** 210mm (A4) for charter-style HTML
- **Cards:** White background, 1px border, light shadow for depth

## Language

- Use **stakeholder organization**, **control function**, **mail system**, **document repository**, **internal AI assistant**
- Avoid archived filenames with `[JP]` prefix in new content

## Module visual coding

| Module | Accent usage |
|--------|----------------|
| ISA | ArchiMate / enterprise alignment diagrams |
| A+I | BPMN / integration / GOAL automation diagrams |
