Dual-Module Architektur-Logik (Technical Breakdown)

1 ISA Modul: Data Intelligence

  • ▶ Ingestion: MSG-Opening Reports und Mail-Daten werden via OCR digitalisiert.
  • ▶ Structuring: Überführung von unstrukturierten Daten (Inhalt der Market Opening Message) in saubere JSON/CSV-Schemata.
  • ▶ Visualization: Automatische Analyse und Bereitstellung fuer Operator (inkl. EXCEPTION HANDLING).
  • ▶ Output: Bereitstellung der Report Mail (inkl. .xlsx Dateien).

2 A+I Modul: Process Automation

  • ▶ Parsing: Tägliche XML-Strukturberichte (Typ A/B) werden programmatisch verarbeitet.
  • ▶ Validation: Applikation von GOAL-Regeln (Prüfung auf Grenzwerte und primäre Violation-Marker).
  • ▶ Governance: Exception-Handling greift nur bei Fehlern; sonst vollautomatischer Durchlauf.
  • ▶ Integration: API-Schnittstelle für SharePoint (Evidence) und DMS (Sign-Off & Archivierung).

Integration Layer (Phase 4)

Beide Module werden im develop Branch via GitHub Actions synchronisiert. Das Resultat ist ein Human-Out-Of-The-Loop System, das Rechnungsdaten aufbereitet, Report-Exceptions validiert und die korrekte DMS-Archivierung garantiert.
