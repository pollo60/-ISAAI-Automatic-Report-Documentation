# ISAAI Project - Automatic Report Documentation

## Overview
Dual-module automation system for invoice processing (ISA) and financial report validation (A+I).

## Project Structure
- `src/isa/` - PDF/OCR Pipeline and Chart Engine
- `src/ai/` - XML Parser and GOAL Exception Rules
- `.github/` - CI/CD and Actions Orchestration
- `docs/` - Architecture documentation (ArchiMate, BPMN)
- `tests/` - Mock XMLs and PDF unit tests

## Branches
- `main` - Stable releases (submission-ready)
- `develop` - Integration branch
- `feature/isa-module` - ISA module development
- `feature/ai-module` - A+I module development
