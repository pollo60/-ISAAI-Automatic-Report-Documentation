# Tests

This folder contains reproducible test data for the ISAAI automated report processing system.

## Contents

- **`runs/`** — 30 simulated daily validation runs (seed=42), each containing:
  - ZIP archive with Report Type A and Report Type B XML files
  - Extracted XML files with ViolationMarker and Threshold1–4 values
  - Evidence CSV files generated by the local flow processor
  - `summary.txt` with the run outcome (Happy / NoEscalation / Exception)
- **`Report_Processing_Log_Local.csv`** — Consolidated log mimicking the SharePoint List schema
- **`Email_Report_Schema (1).xlsx`** — Reference schema for the email-based report structure

## How to Regenerate

```bash
# Generate fresh test data (deterministic with seed)
python3 scripts/simulate_runs.py --count 30 --seed 42

# Process all runs through the local flow simulator
python3 scripts/local_flow_processor.py

# Generate the consolidated PowerPoint audit deck
python3 scripts/generate_automated_presentations.py
```

## Validation Rules

Each XML report is evaluated with a two-step check:
1. **Step 1 — Marker Check**: Is `ViolationMarker` equal to `"V"`? If not → **Pass** (Happy Path)
2. **Step 2 — Threshold Check**: Are any of `Threshold1`–`Threshold4` below 50? If yes → **Violation** (Exception). If no → **Pass** (NoEscalation)
